# DESIGN.md — dsh-session-search

## Product / Purpose

- **Назначение:** Предоставление автономному агенту Ди (Dee) специализированного инструмента (`session_search`) для полнотекстового поиска по истории прошлых сессий DeepSeek Harness через штатный движок ядра `ctx.sessionQuery`.
- **Аудитория:** Автономный агент Ди (Dee), сценарии контекстного воспоминания уроков, поиска прошлых решений и архитектурных ответов.
- **Статус:** Active (Production host-only plugin).

## User Surfaces

- **Web/UI:** UI отсутствует на текущем этапе — плагин полностью **host-only**, клиентских компонентов (React/JSX) и CSS нет.
- **DSH UI / settings / slots:** Слоты интерфейса не регистрируются. Конфигурация плагина осуществляется через схему `Config` Cordis:
  - `maxResults` (number, default: 20): Базовый лимит возвращаемых сессий при поиске.
- **API / Model Tools:**
  - Зарегистрированный инструмент агента: `session_search`.
  - Входные параметры:
    - `query` (string, required): Поисковые термы/запрос.
    - `limit` (integer, optional): Максимум результатов (валидируется и зажимается в диапазон `1..100`, по умолчанию `maxResults`).
  - Формат вывода модели:
    - Успешный результат: список строк вида:
      ```text
      • <Title> [<SessionId>]
        <Snippet совпадения>
      ```
      При наличии курсора следующей страницы добавляется строка:
      ```text
      (есть ещё результаты — уточни запрос)
      ```
    - Пустой результат:
      ```text
      session_search: совпадений не найдено.
      ```
    - Ошибка исполнения движка:
      ```text
      session_search: ошибка: <текст ошибки>
      ```
- **CLI:** Управление через `dsh plugin` и пакетный менеджер `pnpm`.
- **Документация:**
  - `README.md` — каноническое английское руководство;
  - `README.ru.md` — русскоязычное руководство;
  - `docs/design/DESIGN.md` — дизайн-контракт проекта.

## Architecture & Integration

- **Cordis Service Injection:** Плагин объявляет зависимости `export const inject = ['tools', 'sessionQuery']`.
- **Имя и идентичность:**
  - `package.json`: `@goodandready-private/dsh-session-search`;
  - `cordis.patch.yml`: регистрация в бандле под именем `@goodandready-private/dsh-session-search`;
  - `lib/index.js`: `export const name = 'dsh-session-search'` (краткое внутреннее имя плагина в контексте Cordis).
- **Zero Heavy Overhead:** Плагин не запускает собственный FTS-индекс и не распаковывает архивы `.jsonl.zstd` в оперативную память. Он полностью делегирует поиск штатному сервису ядра `@deepseek-ai/dsh-session-query` (SQLite FTS5), обеспечивая минимальное потребление ресурсов и высокую скорость ответа.

## Key Decisions (ADR)

### ADR-001: Язык строк инструмента и статус локализации (Issue #6)

- **Дата:** 2026-09-17
- **Статус:** Accepted
- **Контекст:** В `lib/index.js` зашиты кириллические строки описания инструмента, параметров и текстовых ответов (`session_search: ...`). Автоматические анализаторы фиксируют отсутствие `ctx.locale.register`.
- **Решение:**
  1. Строки инструмента `session_search` зафиксированы на русском языке осознанно. Инструмент спроектирован для русскоязычного автономного агента Ди, чей рабочий контекст и системные промпты ведутся на русском языке.
  2. Так как плагин является **host-only** и не имеет пользовательских интерфейсных компонентов (UI), регистрация в реестре клиентской локализации `ctx.locale.register` не требуется.
  3. Пакет системной локализации `@goodandready/dsh-russian-lang` не затрагивает пространство `dsh-session-search`.
  4. Если в будущем возникнет потребность в мультиязычности описаний инструментов для агента, механизм локализации будет реализован на уровне схемы `defineTool` или конфигурации профиля, без заведения фиктивных клиентских словарей.
